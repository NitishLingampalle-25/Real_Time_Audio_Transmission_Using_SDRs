# Real_Time_Audio_Transmission_Using_SDRs

This project demonstrates a **real-time audio communication system** built using **ADALM-Pluto SDRs** and developed in **MATLAB-Simulink**. It enables secure and efficient transmission and reception of live audio signals over RF.

The primary goal of this project is to create a **secure real-time communication system** suitable for:

- **Military Communications**
- **Emergency Response Communication Systems**

By leveraging **Software Defined Radio (SDR)** technology, the system offers flexibility, rapid deployment, and ease of reconfiguration.


## Tools & Technologies:
- **Hardware**: [ADALM-Pluto SDR](https://wiki.analog.com/university/tools/pluto)
- **Software**: MATLAB & Simulink
